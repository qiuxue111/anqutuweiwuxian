📖 帮助指南

暗区突围：无限 互动地图使用说明。所有容器点位由社区贡献，管理员审核后全球同步。

👤 普通用户操作指南

你可以在互动地图上查看所有共享的容器点位，也可以提交新的点位、评论和建议。

📍 查看容器点位

1 打开 农场地图

2 点击右上角 图层 按钮，勾选你想看的容器类型

3 地图上会显示所有已审核通过的点位图标

4 点击任意图标，查看详细信息和他人评论

✏️ 提交新点位（需要审核）

1 点击控制栏 👁️ 浏览 按钮，切换为 ✏️ 贡献 模式

2 鼠标移到地图上你想添加容器的地方，会显示 金色十字准星

3 点击地图，底部显示坐标，弹出容器类型选择面板

4 选择对应的容器类型（如保险箱、武器箱等）

5 ⚠️ 提交后不会立即全球生效，而是进入 审核队列，管理员审核通过后才会发布

6 但你自己能看到预览效果（显示为蓝色半透明标记）

💡 提示： 贡献模式下十字准星跟随鼠标移动，底部会实时显示当前坐标百分比，方便精确定位。 缩放/平移后坐标仍然精准。

💬 给容器添加评论

1 点击地图上的任意容器图标，弹出详情面板

2 滚动到底部的 评论区

3 输入文字，点击发表

4 评论会进入审核队列，管理员审核后全球可见

🗺️ 地图全局评论

1 页面底部的 地图讨论区

2 可发表对整张地图的想法、建议或攻略心得

3 同样需要审核后全球同步

📝 给容器添加备注

1 点击任意容器图标，打开详情面板

2 在 备注 区填写文本（如刷新点、出什么物资等）

3 点击 保存备注

4 备注进入审核队列，审核后全球同步

🖼️ 给容器添加图片

1 点击容器图标打开详情面板

2 在 图片 区点击 + 按钮

3 选择本地图片上传（目前仅本地预览，云端图片功能开发中）

🗑️ 申请删除点位

1 点击要删除的容器图标

2 点击底部的 🗑 删除此点位

3 确认后，删除申请进入审核队列

4 管理员审核后才会移除

🔍 图层筛选

点击右上角 图层 按钮，弹出分组卡片：

  • 全选 — 一键显示/隐藏所有容器
  • 分组卡片 — 每组有独立标题和组全选勾
  • 支持的类型： 保险箱、武器箱、工具箱、医疗箱、弹药箱、生活箱包、机箱/置物箱、衣服、特殊容器、其他

🔄 检查待审核状态

控制栏上的 待审 N 按钮显示你本地有多少待审批项

点击可查看详情并导出审核文件给管理员

🔐 管理员操作指南

只有你有 GitHub 仓库的 push 权限，所以只有你能将审核队列发布到全球。

📤 审核并发布（完整流程）

1 打开 农场地图

2 点击控制栏 待审 N 按钮

3 弹出窗口中显示所有待审批项的汇总

4 点击 确定 下载 review-queue.json 文件

5 将下载的文件放到网站根目录的 data/ 文件夹内

6 双击 push-to-github.bat 运行

7 脚本会自动：

  • ✅ 读取 data/review-queue.json
  • ✅ 合并新增、删除、修改到 data/pins.json
  • ✅ 删除审核队列文件
  • ✅ 提交到 Git
  • ✅ 推送到 GitHub

8 GitHub Pages 自动部署（约1-2分钟），全球用户即可看到最新点位

📁 文件结构说明

  • data/pins.json — 云端共享点位数据库（所有人读取此文件）
  • data/review-queue.json — 本地审核队列（管理员手动放置）
  • scripts/approve-changes.js — 审核合并脚本（自动运行）
  • push-to-github.bat — 一键上传脚本

⚡ 手动审核（不通过浏览器）

如果你不想从浏览器下载审核文件，可以直接编辑 data/review-queue.json：

{
  "additions": [
    {"x":30,"y":50,"name":"保险箱","type":"safe","ic":"../assets/icons/保险.png","note":"","images":[],"comments":[]}
  ],
  "deletions": [
    {"x":45,"y":22,"type":"weapon"}
  ],
  "edits": [],
  "mapComments": [
    {"text":"写得好！","time":"2026/5/27 04:17:00"}
  ]
}

保存后双击 push-to-github.bat 即可。

🔄 推送失败怎么办？

常见原因：

  • 没有登录 GitHub（需要配置 Personal Access Token）
  • 网络问题（GitHub 需要能正常访问）
  • 分支名问题 — 试 git push -u origin main --force

配置 Token 方法：

  • 访问 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  • 生成一个 Token，勾选 repo 权限
  • 第一次 push 时输入用户名和 Token 作为密码

⏪ 回滚到旧版本

如果发布错了版本，可以在 GitHub 提交历史 找到旧版本，复制旧 data/pins.json 内容覆盖即可。

或在本地执行：

git log --oneline            # 查看提交历史
git checkout <commit-id> -- data/pins.json  # 恢复旧版点位
git add . && git commit -m "回滚点位"
git push

🛡️ 安全说明

  • 任何人都无法直接修改云端数据 — 只有 GitHub 管理员有 push 权限
  • 用户提交的内容全部进入审核队列 — 你审核通过后才会发布
  • 所有修改有 Git 历史 — 可以轻松回滚到任意版本
  • 无后端服务器 — 零维护成本，零安全漏洞
  • ⚠️ 图片上传目前仅保存在上传者自己的浏览器中，云端图片功能规划中

📋 交互操作汇总

  • 鼠标拖动 — 平移地图

  • 点击容器图标 — 查看详情 / 评论
  • 浏览 / 贡献 切换 — 控制栏按钮
  • 十字准星模式 — 贡献模式下自动开启
